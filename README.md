# VSCode Rust Extension Pack

[![Publish Extension](https://github.com/cloudinkcoder/vscode-rust-pack/actions/workflows/publish.yml/badge.svg)](https://github.com/cloudinkcoder/vscode-rust-pack/actions/workflows/publish.yml)

VSCode Extension Pack for Rust development

## Included Extensions

- Rust LSP: [rust-analyzer](https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer)
- Dependency Management Tool: [Dependi](https://marketplace.visualstudio.com/items?itemName=fill-labs.dependi)
- Rust config files: [TOML Support](https://marketplace.visualstudio.com/items?itemName=tamasfe.even-better-toml)
- Debugging: [CodeLLDB](https://marketplace.visualstudio.com/items?itemName=vadimcn.vscode-lldb)
